# 🛡️ CyberShield

## AI-Powered Digital Safety Platform

CyberShield is an interactive digital-safety platform designed to help users identify suspicious online content, understand common cyber threats, improve their security habits, and report suspicious activity.

---

## 🎯 Problem Statement

### Problem Statement 06 — Cybersecurity Awareness & Digital Safety

Users regularly encounter phishing messages, suspicious links, scams, fake accounts, and other online threats. Many users find it difficult to recognize warning signs or understand what action they should take.

CyberShield provides simple, accessible security tools that help users make safer decisions when they encounter potentially risky digital situations.

---

## 💡 Our Solution

CyberShield combines multiple digital-safety tools into one simple platform:

- 🔍 Threat Scanner
- 🛡️ Security Check
- 🤖 AI Safety Assistant
- 🚨 Threat Reporting
- 📊 Security Score
- 📚 Digital Safety Guidance

The platform follows a simple workflow:

**Detect → Understand → Protect → Report**

---

## ✨ Key Features

### 🔍 Threat Scanner

Users can paste suspicious messages, emails, or URLs.

CyberShield checks for common warning indicators such as:

- Urgency language
- Credential requests
- Financial lures
- Suspicious URL patterns
- Phishing-related language

The scanner provides:

- Threat type
- Risk score
- Risk level
- Detected indicators
- Recommended action

---

### 🛡️ Security Check

Users answer five simple questions about their security habits.

The system evaluates areas such as:

- Two-factor authentication
- Device screen locks
- Software updates
- Password reuse
- Data backups

A security score out of 100 is generated to provide a quick awareness assessment.

---

### 🤖 AI Safety Assistant

The AI Safety Assistant allows users to describe a suspicious online situation in natural language.

The current prototype identifies common patterns related to:

- Phishing
- Credential theft
- Scam or financial lures
- Urgency-based manipulation

It then provides an explanation and practical safety guidance.

---

### 🚨 Threat Reporting

Users can report suspicious activity by providing:

- Threat type
- Source/platform
- Suspicious content
- Reason for suspicion

A confirmation screen provides a report ID and status.
